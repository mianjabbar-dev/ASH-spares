#  ASH Spares - Automotive E-Commerce Platform

A full-stack, responsive e-commerce platform designed for an automotive spare parts business based in Faisalabad. It provides a seamless shopping experience for customers and a secure, mobile-friendly administrative dashboard for business management.

##  Tech Stack

* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS & Lucide Icons
* **Database:** PostgreSQL
* **ORM:** Prisma
* **Deployment:** Vercel

## Key Features

* **Modern Storefront:** Fully responsive UI for browsing categories and featured auto parts.
* **Persistent Cart System:** Fast and reliable shopping cart utilizing browser local storage.
* **Secure Admin Dashboard:** A mobile-responsive admin panel to manage products, orders, suppliers, and discounts.
* **Optimized Performance:** Server-side rendering (SSR) and dynamic caching for fast load times.
* **Custom Branding:** Integrated business branding and dynamic image handling.
